HAL Radiator hal-radiator

Build pipeline, runtime architecture & data flow — one SVG card displayed at a time in a rotating carousel
Config layer Build scripts Generated files Data sources Utilities / engine App orchestrator DOM output

How it works: YAML cards defined in radiator.yaml are compiled by build.py into src/config.js. The dev server (serve.py) serves /api/config as JSON + static JS files. The browser boots via app.js: fetches config, then calls showCard() which invokes the appropriate card renderer (e.g. trajectory.js). The renderer uses svg-utils.js and the animation-engine.js to build and animate the SVG into #card. An auto-timer cycles cards after a configurable pause.
